# 아이센스F&B 수불 관리센터 (리빌드 버전)

원본 사이트(https://f-and-b-1.vercel.app/)를 참고해서, 새 구글 스프레드시트를 데이터
소스로 사용하도록 새로 만든 버전입니다. 원본은 소스코드/저장소가 없어(배포된 결과물만
존재) 배포된 HTML/CSS/JS를 분석해서 최대한 동일하게 재구현했습니다.

## 데이터 소스

- 스프레드시트: `src/config.js`의 `SPREADSHEET_ID`
- 브라우저에서 구글 시트의 공개 조회(gviz) API를 직접 호출합니다. **별도 서버나 API
  키가 필요 없지만, 시트가 반드시 "공유 → 일반 액세스 → 링크가 있는 모든 사용자
  (뷰어)"로 설정되어 있어야 합니다.**
- 시트 탭 구성: `PC`, `벌툰`, `꼬치`, `생전포차`(브랜드별, 마진 컬럼 포함), `전범용품목리스트`
  (전체 통합, 마진 컬럼 없음)

## 다른 스프레드시트로 다시 바꾸려면

`src/config.js` 파일에서 아래 값만 수정하면 됩니다.

```js
export const SPREADSHEET_ID = "여기에_새_스프레드시트_ID";
export const BRAND_SHEETS = ["PC", "벌툰", "꼬치", "생전포차"]; // 실제 탭 이름과 반드시 일치해야 함
export const COMBINED_SHEET = "전범용품목리스트";
```

스프레드시트 구조(각 탭의 열 배치: B열=분류, I열=품목코드, J열=품목명, Q열부터 월별
판매수량/매출액(전체 탭)·판매수량/매출액/마진(브랜드 탭)이 순서대로 이어지는 구조)가
동일해야 정상 동작합니다. 구조가 다르면 `src/lib/sheet.js`의 컬럼 매핑을 조정해야 합니다.

## 원본과 달라진 점 (설계 결정 사항)

원본 사이트는 "작년" 스프레드시트 1개 + "올해" 스프레드시트 1개, 총 2개를 연결해서
전년 대비 비교를 보여주는 구조였습니다. 이번에 새로 연결한 스프레드시트는 1개뿐이고
당해 연도 1~12월 데이터만 담고 있어서, 아래와 같이 단순화했습니다.

1. **전년 대비 비교 제거**: "전년 동기 대비" 같은 비교 대신, 해당 연도의 월별 추이와
   누적(YTD) 수치만 보여줍니다. 나중에 전년도 스프레드시트를 추가로 주시면 원본처럼
   연도별 비교 기능을 다시 넣을 수 있습니다.
2. **본사마진 계산 방식 변경**: 원본은 별도의 "매입/매출/수수료" 요약 시트에서
   `매출 - 매입 + 수수료` 공식으로 마진을 계산했습니다. 새 스프레드시트는 브랜드별
   시트에 마진이 이미 계산되어 들어있어서, 그 값을 그대로 합산해서 사용합니다
   (`마감요약` 탭은 사용하지 않았습니다 — 월별로 반복되는 별도 리포트 형식이라 기존
   로직과 구조가 달랐습니다. 필요하시면 이 탭을 활용하는 로직도 추가로 만들 수 있습니다).
3. **브랜드명**: 원본의 "전포차"가 이 스프레드시트에서는 "생전포차"로 되어 있어 그대로
   반영했습니다.

## 로컬에서 실행해보기

```bash
npm install
npm run dev
```

## 배포 (Vercel)

1. 이 프로젝트 폴더를 GitHub 저장소로 올리고 Vercel에서 "Import Project"로 연결하거나,
2. Vercel CLI로 바로 배포: `npx vercel --prod` (프로젝트 루트에서 실행)
3. 또는 `npm run build`로 만든 `dist` 폴더를 Vercel 대시보드에 드래그 앤 드롭해서 배포할
   수도 있습니다.

빌드 명령어는 `npm run build`, 출력 폴더는 `dist` 입니다 (Vite 기본값 그대로라 Vercel이
자동으로 인식합니다).
